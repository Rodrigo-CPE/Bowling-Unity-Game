# Bowling-Unity-Game
Bowl Blast Chaos é um jogo de bowling competitivo para dois jogadores desenvolvido em Unity e C#. O jogo introduz mecânicas caóticas e imprevisíveis através de power-ups que afetam o adversário no turno seguinte (gelo, lama, obstáculos e bola pequena), combinando regras tradicionais com gráficos arcade neon.
